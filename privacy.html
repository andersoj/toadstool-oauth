Privacy Policy

Last updated: October 28, 2026

This Privacy Policy applies to the Toadstool Sports YouTube packaging helper (the “App”), a private tool used by the owner of the Toadstool Sports YouTube channel.

What Google user data we access

The App uses Google OAuth to access the YouTube Data API for the authenticated channel only. Typical scopes cover managing and uploading videos on that channel (for example updating titles, descriptions, tags, and thumbnails, and uploading Shorts).

How we use that data

We use YouTube channel data solely to package and publish the channel owner’s own show content. We do not sell Google user data. We do not use Google user data for advertising. We do not share Google user data with third parties except as required to operate the YouTube API connection itself.

Storage

OAuth tokens needed to keep the App signed in to the channel owner’s Google account are stored securely on the owner’s private systems. Video metadata entered into the App is written to the YouTube channel via Google’s APIs.

Limited use

The App’s use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: use the support email configured on the Google Cloud OAuth consent screen for this project, or reach Toadstool Sports via linktree.com/learntotoad.
